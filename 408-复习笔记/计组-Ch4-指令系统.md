### 一、指令格式

#### 1. 指令结构

```
[操作码 OP] | [地址码 A1] | [地址码 A2] | ...
```

#### 2. 操作码设计

| 方式 | 特点 | 适用 |
|------|------|------|
| **定长操作码** | 所有指令操作码位数相同 | 指令数少、RISC风格 |
| **扩展操作码** | 操作码位数可变，短码给常用指令 | **408常考**，需会数可编码指令数 |
| **哈夫曼编码** | 最短码给最常用指令 | 理论最优 |

> 🔥 **扩展操作码公式**：若n位操作码，k种m位指令，则剩余可编码 $(2^n - k) \times 2^m$ 条更短指令。

#### 3. 地址码结构

| 指令类型 | 操作数来源 | 特点 |
|----------|-----------|------|
| 三地址 | OP A1, A2, A3 | A1←A2 OP A3，指令长 |
| 二地址 | OP A1, A2 | A1←A1 OP A2，最常用 |
| 一地址 | OP A | 隐含ACC，如 `ADD A` = ACC←ACC+A |
| 零地址 | OP | 操作数隐含（堆栈/空操作） |

### 二、寻址方式 ⭐（选择题必考）

#### 1. 10种寻址方式速查

| 寻址方式 | 操作数位置 | EA（有效地址） |
|----------|-----------|---------------|
| **立即寻址** | 指令中直接给出 | 无（操作数=指令中的立即数） |
| **直接寻址** | EA = 地址码 | EA = A |
| **间接寻址** | EA = 内存[A] | EA = (A) |
| **寄存器寻址** | 寄存器中 | 无（操作数=Rn） |
| **寄存器间接** | EA = 寄存器内容 | EA = (Rn) |
| **变址寻址** | EA = (IX) + A | EA = (IX) + A |
| **基址寻址** | EA = (BR) + A | EA = (BR) + A |
| **相对寻址** | EA = (PC) + A | EA = (PC) + A（多用于转移指令） |
| **堆栈寻址** | 栈顶 | 隐含SP |
| **复合寻址** | 如先变址再间接 | EA = ((IX) + A) |

#### 2. 变址 vs 基址（关键区分）

| 对比 | 变址寻址 | 基址寻址 |
|------|----------|----------|
| 寄存器 | 变址寄存器 IX | 基址寄存器 BR |
| 谁变？ | **指令地址码A不变，IX可变** | **BR不变，A可变** |
| 用途 | 数组访问（循环中IX自增） | 程序重定位（多道程序） |
| 谁编入？ | A是**形式地址**（数组首址） | BR是**基地址**，A是**偏移量** |

> 🔥 相对寻址中，(PC)是程序计数器当前值，A是补码偏移量（可正可负）。

### 三、CISC vs RISC ⭐

| 对比维度 | CISC（复杂指令集） | RISC（精简指令集） |
|----------|-------------------|-------------------|
| 指令数目 | 多 | 少（通常<100条） |
| 指令字长 | 可变 | **定长** |
| 寻址方式 | 多种 | 少（通常只有LOAD/STORE访存） |
| 执行时间 | 差异大 | **大多一个周期** |
| 控制方式 | **微程序控制** | **硬布线控制** |
| 寄存器数量 | 少 | 多（大量通用寄存器） |
| 编译器 | 简单 | 复杂（需优化编译） |
| 代表 | x86 | ARM、MIPS、RISC-V |

### 四、易错点

- ❌ 变址寻址是形式地址A在变 → ✅ 变址寄存器IX在变，A不变
- ❌ CISC用硬布线，RISC用微程序 → ✅ 恰好相反：CISC微程序，RISC硬布线
- ⚠️ 间接寻址访问内存1次以上；寄存器寻址不访存
