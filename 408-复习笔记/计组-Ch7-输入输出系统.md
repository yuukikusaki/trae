### 一、I/O接口

| 功能 | 说明 |
|------|------|
| 数据缓冲 | 匹配速度差异 |
| 信号转换 | 电平/格式转换 |
| 地址译码 | 识别本设备 |
| 中断/DMA控制逻辑 | 配合中断/DMA使用 |

#### I/O端口编址

| 方式 | 特点 | 代表 |
|------|------|------|
| **统一编址（内存映射I/O）** | I/O端口与内存统一编址，用访存指令访问 | ARM、MIPS |
| **独立编址（I/O映射I/O）** | I/O端口独立编址，需专用I/O指令 | x86（IN/OUT指令） |

### 二、中断系统 ⭐

#### 1. 中断优先级与屏蔽

| 概念 | 说明 |
|------|------|
| **中断优先级** | 多个中断同时请求时，响应优先级高的 |
| **中断屏蔽** | 通过屏蔽字禁止某些中断（可在中断服务程序中设置） |
| **多重中断** | 高优先级中断可打断低优先级中断服务程序 |

> 🔥 **中断屏蔽触发器**：=1时屏蔽**本级及更低级**中断（不是只屏蔽本级）

#### 2. 中断响应条件

1. 中断源有请求
2. CPU允许中断（IF=1）
3. **一条指令执行结束**时才响应（不是任意时刻！）

#### 3. 中断隐指令（硬件自动完成）

1. **关中断**（IF←0）
2. **保存断点**（PC→堆栈）
3. **引出中断服务程序**（中断向量→PC）

### 三、DMA方式 ⭐

#### 1. DMA vs 中断

| 对比 | 中断 | DMA |
|------|------|-----|
| 数据传送单位 | 字/字节 | **数据块** |
| 数据传送方向 | 外设↔CPU↔内存 | 外设↔内存（不经过CPU） |
| CPU干预 | 每个数据传输都有 | 仅预处理和后处理 |
| 请求响应时机 | 指令执行结束 | **任意时刻可响应**（只需总线） |
| 优先级 | 低于DMA | **高于中断** |

#### 2. DMA传送方式

| 方式 | 说明 |
|------|------|
| **停止CPU访问** | DMA期间CPU暂停（效率低） |
| **周期挪用** | DMA窃取一个总线周期 | 
| **交替访问** | CPU和DMA交替使用总线 |

> 🔥 周期挪用是最常用的方式——DMA控制器"偷"一个总线周期来完成一次数据传送。

#### 3. DMA工作过程

```
① 预处理：CPU初始化DMA（源/目的地址、传送字数、方向）
② 数据传送：DMA控制器控制总线，完成块传送
③ 后处理：传送结束，DMA向CPU发中断请求
```

### 四、易错点

- ❌ DMA比中断优先级低 → ✅ DMA优先级**高于**中断（需要快速响应）
- ❌ 中断只能在指令边界响应 → ✅ 对中断如此；但DMA可在任意总线周期响应
- ⚠️ 中断隐指令是**硬件完成**的，不是程序员编写的
