### 一、内存管理概述

#### 1. 程序运行步骤

```
编译 → 链接（静态/装入时动态/运行时动态） → 装入（绝对/可重定位/运行时动态）
```

#### 2. 逻辑地址 vs 物理地址

- **逻辑地址**：CPU生成的地址（编译后确定）
- **物理地址**：内存单元的实际地址
- **MMU（内存管理单元）**：负责逻辑→物理的转换（含**重定位寄存器/基址寄存器**）

### 二、连续分配管理方式

| 方式 | 思想 | 特点 | 外部碎片 |
|------|------|------|----------|
| 单一连续 | 内存分系统区+用户区 | 简单，只用于单用户 | 有 |
| 固定分区 | 预划分固定大小分区 | 内部碎片严重 | 无 |
| 动态分区 | 按需分配，大小可变 | 外部碎片 → 需**紧凑** | 有 |

#### 动态分区分配算法

| 算法 | 思想 | 特点 |
|------|------|------|
| **首次适应(FF)** | 找到第一个够大的空闲块 | 简单快速，低地址产生碎片 |
| **最佳适应(BF)** | 找最接近大小的空闲块 | 产生最多小碎片 |
| **最坏适应(WF)** | 找最大的空闲块 | 减少小碎片 |
| **循环首次适应(NF)** | 从上次找到的位置继续 | 使空闲区分布均匀 |

### 三、分页存储管理 ⭐（核心考点）

#### 1. 基本概念

| 概念 | 说明 |
|------|------|
| **页(Page)** | 逻辑地址空间的固定大小块 |
| **页框/帧(Frame)** | 物理内存的固定大小块（与页等大） |
| **页表** | 记录每个页对应的物理页框号 |
| **页内偏移** | 逻辑地址低位，物理地址直接继承 |

#### 2. 地址变换 ⭐

```
逻辑地址 A → 页号 P = A / 页面大小, 页内偏移 W = A % 页面大小
查页表：物理块号 B = 页表[P].块号
物理地址 = B × 页面大小 + W
```

#### 3. TLB 与多级页表

| 技术 | 目的 | 原理 |
|------|------|------|
| **TLB（快表）** | 加速地址变换 | 缓存最近使用的页表项（命中→跳过访存） |
| **多级页表** | 节省页表空间 | 将页表再分页，不存在的次级页表不分配 |

> 🔥 **TLB命中时**：有效访存时间 = TLB访问时间 + 一次访存

#### 4. 访问内存次数分析（常考）

| 场景 | 访存次数 |
|------|----------|
| 无TLB、单级页表 | **2次**（页表+数据） |
| 无TLB、两级页表 | **3次**（一级+二级+数据） |
| TLB命中、单级页表 | **1次**（TLB命中直接访数据） |
| TLB未命中、单级页表 | **2次**（页表+数据；之后更新TLB） |

### 四、分段与段页式管理

| 方式 | 优势 | 劣势 |
|------|------|------|
| **分段** | 符合用户逻辑（代码段/数据段），便于共享保护 | 外部碎片，内存利用率低 |
| **段页式** | 兼有两家之长 | 三次访存（段表→页表→数据），复杂 |

### 五、虚拟内存管理 ⭐

#### 1. 核心概念

- **虚拟内存**：逻辑上扩充内存的容量，作业不必全部装入即可运行
- **基础**：局部性原理（时间局部性+空间局部性）
- **实现方式**：请求分页 / 请求分段

#### 2. 页面置换算法 ⭐（408高频考点）

| 算法 | 规则 | Belady异常 | 实现 |
|------|------|------------|------|
| **OPT** | 替换未来最久不用的 | 无 | 理论最优，不可实现 |
| **FIFO** | 先进先出 | **有**（唯一的产生者！） | 队列 |
| **LRU** | 替换最久未用的 | 无 | 栈/计数器，开销大 |
| **CLOCK(NRU)** | 循环扫描，访问位=0则淘汰 | 无 | 近似LRU，实用 |
| **改进CLOCK** | 优先淘汰(0,0)→(0,1)→(1,0)→(1,1) | 无 | 更优 |

> 🔥 **Belady异常**：给更多物理块，缺页率反而升高！只有FIFO会产生。

#### 3. 缺页率影响因素

- 页面大小：太大→浪费，太小→缺页频繁
- 物理块数：越多→缺页越低（FIFO不一定）
- 置换算法：LRU > CLOCK > FIFO
- 程序局部性：好→缺页少

#### 4. 抖动(Thrashing)与工作集

| 概念 | 含义 |
|------|------|
| **抖动** | 频繁缺页，CPU大量时间用于对换而非执行 |
| **工作集** | 某时间段内进程实际访问的页集合 |
| **防治** | 减少并发进程数；工作集模型；缺页频度控制 |

### 六、易错点

- ❌ 缺页中断属于外中断 → ✅ 缺页属于**内中断（异常）**
- ❌ 页面越大越好 → ✅ 页面过大会增加内部碎片和I/O开销
- ⚠️ 只有FIFO有Belady异常！LRU和CLOCK都没有
- ⚠️ 虚拟地址→物理地址，**页内偏移量不变**
