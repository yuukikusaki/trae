# 操作系统 第4章 文件管理

### 一、文件系统基础

#### 1. 文件逻辑结构

| 类型 | 结构 | 存取方式 |
|------|------|----------|
| 流式文件 | 无结构字节序列 | 顺序 |
| 记录式文件 | 定长/变长记录 | 顺序/随机 |

#### 2. 文件操作

| 操作 | 说明 |
|------|------|
| Create/Delete | 创建/删除文件 |
| Open/Close | 打开（建立FCB→内存）/关闭 |
| Read/Write | 读/写数据 |
| Seek | 定位文件指针 |

> 🔥 **打开文件**：将FCB（文件控制块）从磁盘读入内存；关闭则写回。

### 二、目录结构

| 结构 | 特点 | 问题 |
|------|------|------|
| 单级目录 | 全部文件一个目录 | 命名冲突 |
| 两级目录 | 主目录(MFD) + 用户目录(UFD) | 用户间不能共享 |
| **树形目录** | 多级层次，**现代OS主流** | 查找快，可重名 |
| 无环图目录 | 可共享同一文件 | 删除需引用计数 |

### 三、文件物理结构 ⭐

#### 1. 三种分配方式对比

| 方式 | 实现 | 优点 | 缺点 | 代表 |
|------|------|------|------|------|
| **连续分配** | 文件占连续磁盘块 | 简单，顺序访问快 | 外部碎片，需预知大小 | — |
| **隐式链接** | 每块含下一块指针 | 无碎片，可动态增长 | 只能顺序访问，指针占空间 | — |
| **显式链接(FAT)** | 链接指针集中存入FAT表 | FAT在内存→随机访问快 | FAT表本身占用空间 | FAT文件系统 |
| **索引分配** | 索引块存储所有块号 | 支持随机访问 | 索引块额外开销 | Unix/Linux inode |

#### 2. 索引分配进阶

| 变体 | 原理 |
|------|------|
| **单级索引** | 一个索引块指向所有数据块 |
| **多级索引** | 索引块指向更次级索引块 |
| **混合索引** | 直接块 + 一级间接 + 二级间接 + 三级间接（Unix inode方式） |

> 🔥 **Unix混合索引**：小文件用直接块（快速），大文件逐级间接（扩展容量）。408常考文件最大长度的计算。

### 四、文件存储空间管理

| 方法 | 原理 | 特点 |
|------|------|------|
| **空闲表法** | 连续空闲区表 | 类似动态分区 |
| **空闲链表法** | 空闲块串联成链 | 效率低 |
| **位示图法** | 1bit表示1块是否空闲 | **最常用**，适合向量运算 |
| **成组链接法** | 分组链接，最后一组首块存下一组信息 | Unix采用 |

> 🔥 **位示图计算**：字号 i = 块号 / 字长，位号 j = 块号 % 字长

### 五、文件共享与保护

| 概念 | 说明 |
|------|------|
| **硬链接** | 多个目录项指向**同一inode**，引用计数+1；删除一个不减到0则不释放 |
| **软链接(符号链接)** | 新建文件存目标路径；删除原文件则链接失效（类似快捷方式） |

> 🔥 **硬链接不能跨文件系统，不能链接目录；软链接可以。**

### 六、磁盘管理 ⭐

#### 1. 磁盘访问时间

$$T = T_s + T_r + T_t$$

| 分量 | 含义 |
|------|------|
| $T_s$（寻道时间） | 磁头移动到目标柱面（**占比最大**） |
| $T_r$（旋转延迟） | 扇区旋转到磁头下（平均 = 转一圈时间/2） |
| $T_t$（传输时间） | 实际读写数据的时间 |

#### 2. 磁盘调度算法（常考计算题）

| 算法 | 策略 | 特点 | 饥饿 |
|------|------|------|------|
| **FCFS** | 按请求顺序 | 公平但性能差 | 无 |
| **SSTF** | 最短寻道时间优先 | 性能较好 | **有**（远处请求可能饿死） |
| **SCAN（电梯）** | 单向移动到头再折返 | 较好 | 边缘磁道稍不利 |
| **C-SCAN** | 单向移动，到最远端直接跳到最内端 | 更公平（循环） | 改善边缘 |
| **LOOK** | SCAN变体：到最远请求即折返 | 实际采用（Linux） | — |
| **C-LOOK** | C-SCAN变体：到两端请求即跳回 | 实用 | — |

### 七、易错点

- ❌ 文件打开时就把全部数据读入内存 → ✅ 只是FCB进内存，数据仍在外存
- ❌ 硬链接是复制一份文件 → ✅ 硬链接是**别名**，指向同一inode
- ⚠️ 磁盘访问时间中，寻道时间占主导，所以SSTF主要优化寻道
- ⚠️ 成组链接法中，空闲盘块号栈放在每组最后一个空闲块中
