# 考研数理统计 · 假设检验

> 假设检验是参数估计的"镜像"——同样的枢轴量，不同的用法
>
> 适用人群：考研数学一/三考生 | 用途：日常背诵记忆 · 逐步学习 · 考前速查

---

# 第一部分　假设检验基本概念

## 1.1　核心术语

| 术语               | 记号          | 含义                                     |
| ---------------- | ----------- | -------------------------------------- |
| **原假设（零假设）**     | $H_0$       | 要检验的假设，通常设为"无差异"、"等于"                 |
| **备择假设**         | $H_1$       | 与原假设对立的假设                              |
| **检验统计量**        | —           | 用于判断$H_0$是否成立的统计量                      |
| **显著性水平**        | $\alpha$    | 犯第一类错误的概率上限（通常取$0.05$或$0.01$）          |
| **拒绝域**          | $W$         | 当检验统计量落入此区域时拒绝$H_0$                    |
| **接受域**          | —           | 拒绝域的补集                                  |
| **$p$值**         | $p$-value   | 在原假设下观察到比当前更极端结果的概率                    |

> ★ **$H_0$和$H_1$不是对称的！** $H_0$受"保护"——要有充分证据才能拒绝它（类似"无罪推定"）。

## 1.2　两类错误

| 错误类型            | 定义                    | 概率                                |
| --------------- | --------------------- | --------------------------------- |
| **第一类错误（弃真）**   | $H_0$为真但拒绝$H_0$       | $P\{\text{拒绝}H_0\mid H_0\text{真}\}=\alpha$ |
| **第二类错误（取伪）**   | $H_0$为假但接受$H_0$       | $P\{\text{接受}H_0\mid H_0\text{假}\}=\beta$  |

> ★ **两类错误的关系：** 样本量固定时，$\alpha\downarrow\;\Rightarrow\;\beta\uparrow$（此消彼长）。增加样本量$n$可以同时降低两者。

## 1.3　假设检验的步骤

> **五步法（考研标准答题模板）**

1. **建立假设：** 写出$H_0$和$H_1$
2. **选择检验统计量并确定分布：** 如$Z,\;t,\;\chi^2,\;F$
3. **给定显著性水平$\alpha$，确定拒绝域**
4. **计算检验统计量的观测值**
5. **做出判断：** 若观测值落入拒绝域，则拒绝$H_0$；否则不拒绝$H_0$

# 第二部分　单个正态总体的假设检验

## 2.1　均值的检验

### 情况一：$\sigma^2$已知 — $Z$检验

| 项目       | 内容                                              |
| -------- | ----------------------------------------------- |
| $H_0$    | $\mu=\mu_0$                                     |
| 检验统计量    | $Z=\dfrac{\bar{X}-\mu_0}{\sigma/\sqrt{n}}\sim N(0,1)$（$H_0$成立时） |
| 拒绝域（双侧$H_1:\mu\neq\mu_0$） | $\vert Z\vert\ge z_{\alpha/2}$                  |
| 拒绝域（右侧$H_1:\mu>\mu_0$） | $Z\ge z_{\alpha}$                                |
| 拒绝域（左侧$H_1:\mu<\mu_0$） | $Z\le -z_{\alpha}$                               |

> ★ **双侧用$z_{\alpha/2}$，单侧用$z_{\alpha}$**——不要搞混！

### 情况二：$\sigma^2$未知 — $t$检验

| 项目       | 内容                                              |
| -------- | ----------------------------------------------- |
| $H_0$    | $\mu=\mu_0$                                     |
| 检验统计量    | $T=\dfrac{\bar{X}-\mu_0}{S/\sqrt{n}}\sim t(n-1)$（$H_0$成立时） |
| 拒绝域（双侧$H_1:\mu\neq\mu_0$） | $\vert T\vert\ge t_{\alpha/2}(n-1)$              |
| 拒绝域（右侧$H_1:\mu>\mu_0$） | $T\ge t_{\alpha}(n-1)$                            |
| 拒绝域（左侧$H_1:\mu<\mu_0$） | $T\le -t_{\alpha}(n-1)$                           |

---

## 2.2　方差的检验 — $\chi^2$检验

| 项目       | 内容                                                |
| -------- | ------------------------------------------------- |
| $H_0$    | $\sigma^2=\sigma_0^2$                             |
| 检验统计量    | $\chi^2=\dfrac{(n-1)S^2}{\sigma_0^2}\sim\chi^2(n-1)$（$H_0$成立时） |

### 拒绝域

| 备择假设                     | 拒绝域                                         |
| ------------------------ | ------------------------------------------- |
| $H_1:\sigma^2\neq\sigma_0^2$（双侧） | $\chi^2\ge\chi^2_{\alpha/2}(n-1)$或$\chi^2\le\chi^2_{1-\alpha/2}(n-1)$ |
| $H_1:\sigma^2>\sigma_0^2$（右侧） | $\chi^2\ge\chi^2_\alpha(n-1)$                |
| $H_1:\sigma^2<\sigma_0^2$（左侧） | $\chi^2\le\chi^2_{1-\alpha}(n-1)$            |

> ★ **特别注意：** $\chi^2$分布的拒绝域一般不是对称的！双侧时两端分位点不同。

---

# 第三部分　两个正态总体的假设检验

## 3.1　两总体均值差的检验

### 情况三：$\sigma_1^2,\sigma_2^2$已知 — $Z$检验

| 项目       | 内容                                                 |
| -------- | -------------------------------------------------- |
| $H_0$    | $\mu_1-\mu_2=\delta$（通常$\delta=0$）                 |
| 检验统计量    | $Z=\dfrac{(\bar{X}-\bar{Y})-\delta}{\sqrt{\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}}}\sim N(0,1)$ |

### 情况四：$\sigma_1^2=\sigma_2^2=\sigma^2$未知 — 两样本$t$检验

| 项目       | 内容                                                 |
| -------- | -------------------------------------------------- |
| $H_0$    | $\mu_1-\mu_2=\delta$                               |
| 检验统计量    | $T=\dfrac{(\bar{X}-\bar{Y})-\delta}{S_w\sqrt{\frac{1}{n_1}+\frac{1}{n_2}}}\sim t(n_1+n_2-2)$ |
| 合并方差     | $S_w^2=\dfrac{(n_1-1)S_1^2+(n_2-1)S_2^2}{n_1+n_2-2}$ |

> ★ **这是考研最高频的双样本检验！** $S_w$是"加权平均的样本方差"。

### 情况五：$\sigma_1^2\neq\sigma_2^2$且未知（大样本）

> 近似使用$Z$检验，用$S_1^2,S_2^2$代替$\sigma_1^2,\sigma_2^2$。

### 情况六：配对样本（成对比较）

| 项目       | 内容                                                 |
| -------- | -------------------------------------------------- |
| 场景       | 同一样本在两种条件下的测量，如服药前后                               |
| 思路       | 计算差值$D_i=X_i-Y_i$，转化为单样本$t$检验                       |
| $H_0$    | $\mu_D=0$                                          |
| 检验统计量    | $T=\dfrac{\bar{D}}{S_D/\sqrt{n}}\sim t(n-1)$        |

> ★ **配对检验考法隐蔽：** "$n$个患者服药前后的血压数据"→ 立即反应这是配对检验！

---

## 3.2　两总体方差比的检验 — $F$检验

| 项目       | 内容                                                 |
| -------- | -------------------------------------------------- |
| $H_0$    | $\sigma_1^2=\sigma_2^2$（或$\sigma_1^2/\sigma_2^2=1$） |
| 检验统计量    | $F=\dfrac{S_1^2}{S_2^2}\sim F(n_1-1,n_2-1)$（$H_0$成立时） |

### 拒绝域

| 备择假设                     | 拒绝域                                                   |
| ------------------------ | ----------------------------------------------------- |
| $H_1:\sigma_1^2\neq\sigma_2^2$（双侧） | $F\ge F_{\alpha/2}(n_1-1,n_2-1)$或$F\le F_{1-\alpha/2}(n_1-1,n_2-1)$ |
| $H_1:\sigma_1^2>\sigma_2^2$（右侧） | $F\ge F_\alpha(n_1-1,n_2-1)$                           |
| $H_1:\sigma_1^2<\sigma_2^2$（左侧） | $F\le F_{1-\alpha}(n_1-1,n_2-1)$                       |

> ★ **$F$检验通常用来验证"方差齐性"——这是两样本$t$检验的前提！**

# 第四部分　假设检验速查总表

## 单个正态总体$N(\mu,\sigma^2)$

| 检验目标            | $\sigma^2$情况 | 检验统计量                          | 分布            | 拒绝域公式                                    |
| --------------- | ----------- | ------------------------------ | ------------- | ---------------------------------------- |
| $H_0:\mu=\mu_0$ | $\sigma^2$已知 | $Z=\dfrac{\bar{X}-\mu_0}{\sigma/\sqrt{n}}$ | $N(0,1)$      | $\vert Z\vert\ge z_{\alpha/2}$           |
| $H_0:\mu=\mu_0$ | $\sigma^2$未知 | $T=\dfrac{\bar{X}-\mu_0}{S/\sqrt{n}}$ | $t(n-1)$      | $\vert T\vert\ge t_{\alpha/2}(n-1)$      |
| $H_0:\sigma^2=\sigma_0^2$ | $\mu$未知    | $\chi^2=\dfrac{(n-1)S^2}{\sigma_0^2}$ | $\chi^2(n-1)$ | $\chi^2\ge\chi^2_{\alpha/2}$或$\chi^2\le\chi^2_{1-\alpha/2}$ |

## 两个正态总体

| 检验目标                        | 条件                          | 检验统计量                                        | 分布               | 自由度              |
| --------------------------- | --------------------------- | -------------------------------------------- | ---------------- | ---------------- |
| $H_0:\mu_1=\mu_2$           | $\sigma_1^2,\sigma_2^2$已知   | $Z$                                          | $N(0,1)$         | —                |
| $H_0:\mu_1=\mu_2$           | $\sigma_1^2=\sigma_2^2$未知  | $T=\dfrac{\bar{X}-\bar{Y}}{S_w\sqrt{\frac{1}{n_1}+\frac{1}{n_2}}}$ | $t$              | $n_1+n_2-2$      |
| $H_0:\mu_1=\mu_2$           | 配对样本                       | $T=\dfrac{\bar{D}}{S_D/\sqrt{n}}$             | $t$              | $n-1$            |
| $H_0:\sigma_1^2=\sigma_2^2$ | $\mu_1,\mu_2$未知            | $F=\dfrac{S_1^2}{S_2^2}$                     | $F$              | $(n_1-1,n_2-1)$  |

# 第五部分　区间估计 vs 假设检验对照

> ★ **考研关键洞察：同一问题可以用两种方法解决！**

| 维度       | 区间估计           | 假设检验              |
| -------- | -------------- | ----------------- |
| 目的       | 给出参数的可能范围      | 判断参数是否等于某个值       |
| 输出       | 一个区间$[L,U]$    | "拒绝$H_0$" / "不拒绝$H_0$" |
| 核心工具     | 枢轴量$+$分位点     | 检验统计量$+$拒绝域       |
| 等价关系     | 若$\mu_0$落入$\mu$的置信区间，则不应拒绝$H_0:\mu=\mu_0$ |
| 考研趋势     | 常出计算题          | 常出概念题$+$计算题       |

> ★ **一句话：** $\mu_0$在置信区间内$\Leftrightarrow$不拒绝$H_0:\mu=\mu_0$（显著性水平相同）

# 第六部分　考研易错点汇总

> **① 拒绝域的方向：** 拒绝域要和备择假设方向一致（$H_1:\mu>\mu_0\Rightarrow$右侧拒绝域）
>
> **② 双侧 vs 单侧分位数：** 双侧用$\alpha/2$，单侧用$\alpha$
>
> **③ $t$检验 vs $Z$检验：** 只要题目没给$\sigma$（或给了样本标准差$S$），就用$t$！
>
> **④ 自由度别写错：** 单样本均值的$t$检验，自由度是$n-1$（不是$n$！）
>
> **⑤ $\chi^2$检验的拒绝域不对称：** 不要写成对称的$\pm$形式
>
> **⑥ "接受$H_0$" vs "不拒绝$H_0$"：** 严格来说应说"不拒绝$H_0$"（因为$\beta$未知）
>
> **⑦ 配对检验 vs 两独立样本检验：** 看数据是否一一配对
>
> **⑧ $F$检验的分位点换算：** $F_{1-\alpha}(n_1,n_2)=1/F_\alpha(n_2,n_1)$

# 第七部分　假设检验五步模板（答题用）

```
解：
(1) 建立假设：H₀: μ = μ₀  vs  H₁: μ ≠ μ₀（或 > / <）
(2) 选检验统计量：σ²未知，选 T = (X̄-μ₀)/(S/√n) ~ t(n-1)
(3) 给定显著性水平 α = 0.05，拒绝域：|T| ≥ t_{0.025}(n-1)
(4) 计算：代入数据得 T 的观测值 = ______
(5) 判断：
    - 若 |T| ≥ t_{0.025}(n-1)，拒绝 H₀，认为有显著差异
    - 若 |T| < t_{0.025}(n-1)，不拒绝 H₀，认为无显著差异
```

# 第八部分　考研必背口诀

> **"$Z$检验看方差已知，$T$检验看方差未知；
> 卡方检验看一个方差，$F$检验看方差比；
> 双侧$\alpha/2$上下各半，单侧$\alpha$偏向一边；
> 配对设计要相减，独立样本看合并。"**
