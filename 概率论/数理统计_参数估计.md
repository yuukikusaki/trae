>
> 适用人群：考研数学一/三考生 | 用途：日常背诵记忆 · 逐步学习 · 考前速查

# 第一部分　点估计

## 1.1　矩估计法（Method of Moments）

### 基本原理

> **用样本矩代替总体矩，解出参数的估计值。**

### 操作步骤

1. 计算总体矩$\mu_k=E(X^k)$，用未知参数表示
2. 计算样本矩$A_k=\frac{1}{n}\sum X_i^k$
3. 令$\mu_k=A_k$，建立方程
4. 解方程得参数的矩估计量

> ★ **需要几个方程？** 有几个未知参数就建几个方程的方程组。

### 常见分布的矩估计结果

| 分布                     | 参数             | 矩估计量                                            |
| ---------------------- | -------------- | ------------------------------------------------ |
| 二项分布$B(n,p)$          | $p$            | $\hat{p}=\bar{X}/n$                              |
| 泊松分布$P(\lambda)$      | $\lambda$      | $\hat{\lambda}=\bar{X}$                          |
| 均匀分布$U(a,b)$          | $a,\;b$        | $\hat{a}=\bar{X}-\sqrt{3}B_2,\;\hat{b}=\bar{X}+\sqrt{3}B_2$ |
| 指数分布$E(\lambda)$      | $\lambda$      | $\hat{\lambda}=1/\bar{X}$                        |
| 正态分布$N(\mu,\sigma^2)$ | $\mu,\;\sigma^2$ | $\hat{\mu}=\bar{X},\;\hat{\sigma}^2=B_2=\frac{1}{n}\sum(X_i-\bar{X})^2$ |

> ★ **注意：** 均匀分布$U(a,b)$的矩估计公式不是直观的$\min/\max$！而是$\hat{a}=\bar{X}-\sqrt{3}\,S_n,\;\hat{b}=\bar{X}+\sqrt{3}\,S_n$（其中$S_n^2=B_2$）

## 1.2　最大似然估计法（MLE）

### 基本原理

> **选择使样本出现概率（或概率密度）最大的参数值作为估计。**

### 操作步骤

1. **写出似然函数：** 离散型$L(\theta)=\prod P\{X_i=x_i;\theta\}$；连续型$L(\theta)=\prod f(x_i;\theta)$
2. **取对数：** $\ln L(\theta)=\sum\ln f(x_i;\theta)$（将乘积转求和）
3. **求导（组）：** $\dfrac{\partial\ln L}{\partial\theta}=0$
4. **解似然方程：** 得$\hat{\theta}_{\text{MLE}}$
5. **验证最大值：** 二阶导数$<0$或直接判定

### 常见分布的 MLE 结果

| 分布                     | 参数               | 最大似然估计量                                         |
| ---------------------- | ---------------- | ----------------------------------------------- |
| 0-1分布$B(1,p)$         | $p$              | $\hat{p}=\bar{X}$                               |
| 二项分布$B(n,p)$          | $p$              | $\hat{p}=\bar{X}/n$                             |
| 泊松分布$P(\lambda)$      | $\lambda$        | $\hat{\lambda}=\bar{X}$                         |
| 指数分布$E(\lambda)$      | $\lambda$        | $\hat{\lambda}=1/\bar{X}$                       |
| 正态分布$N(\mu,\sigma^2)$ | $\mu,\;\sigma^2$  | $\hat{\mu}=\bar{X},\;\hat{\sigma}^2=\frac{1}{n}\sum(X_i-\bar{X})^2$ |
| 均匀分布$U(0,\theta)$    | $\theta$         | $\hat{\theta}=\max\{X_1,\ldots,X_n\}$           |
| 均匀分布$U(a,b)$          | $a,\;b$          | $\hat{a}=\min\{X_i\},\;\hat{b}=\max\{X_i\}$     |

> ★ **$U(0,\theta)$和$U(a,b)$是考研最爱的MLE考点！** 它们不能通过求导得到（似然函数不是处处可导），需要用单调性分析。

### 矩估计 vs MLE 对比

| 对比维度   | 矩估计           | 最大似然估计          |
| ------ | -------------- | --------------- |
| 原理     | 样本矩$=$总体矩     | 最大化似然函数         |
| 计算难度   | 一般较简单          | 需要求导/单调性        |
| 性质     | 不一定是最优         | 一般有优良的大样本性质     |
| 均匀分布   | 公式复杂           | $\min$/$\max$（简单） |
| 考研频率   | ★★★★           | ★★★★★           |

# 第二部分　估计量的评选标准

## 2.1　无偏性（Unbiasedness）

> **定义：** 若$E(\hat{\theta})=\theta$，则称$\hat{\theta}$是$\theta$的无偏估计量。

### 考研必记的无偏性结论

| 估计量                               | 是否无偏     | 说明                            |
| --------------------------------- | -------- | ----------------------------- |
| $\bar{X}$是$\mu$的无偏估计              | ✅        | $E(\bar{X})=\mu$              |
| $S^2$是$\sigma^2$的无偏估计            | ✅        | $E(S^2)=\sigma^2$             |
| $B_2$不是$\sigma^2$的无偏估计           | ❌        | $E(B_2)=\frac{n-1}{n}\sigma^2\neq\sigma^2$ |
| MLE的$\hat{\sigma}^2$不是$\sigma^2$的无偏估计 | ❌        | 同上，分母是$n$而不是$n-1$              |
| 样本标准差$S$不是$\sigma$的无偏估计           | ❌        | 一般$E(S)\neq\sigma$            |
| $X_1$是$\mu$的无偏估计                  | ✅        | 但方差大，不是好估计                    |

> ★ **无偏$\neq$最好。** 例如$X_1$也是$\mu$的无偏估计，但$\bar{X}$的方差是它的$1/n$，$\bar{X}$更好。

## 2.2　有效性（Efficiency）

> **定义：** 若$\hat{\theta}_1$和$\hat{\theta}_2$都是$\theta$的无偏估计，且$D(\hat{\theta}_1)<D(\hat{\theta}_2)$，则称$\hat{\theta}_1$比$\hat{\theta}_2$更有效。

> ★ **有效性的前提是"同为无偏"！** 不能拿一个有偏估计和一个无偏估计比方差。

## 2.3　相合性 / 一致性（Consistency）

> **定义：** 若$\hat{\theta}_n\xrightarrow{P}\theta$（依概率收敛，$n\to\infty$），则称$\hat{\theta}_n$是$\theta$的相合估计量。

> ★ $\bar{X}$是$\mu$的相合估计；$S^2$是$\sigma^2$的相合估计。MLE在一般条件下也是相合的。

# 第三部分　区间估计（置信区间）

> ★ **区间估计是考研大题的最爱！** 关键在于"套公式"$+$选对分布。

## 3.0　置信区间通用公式

> **点估计 $\pm$ 分位数 $\times$ 标准误差**

| 元素     | 含义                        |
| ------ | ------------------------- |
| 点估计    | $\hat{\theta}$（矩估计或MLE给出的值） |
| 分位数    | 从$Z$/$t$/$\chi^2$/$F$表查得   |
| 标准误差   | 点估计的标准差或其估计               |

---

## 3.1　单个正态总体$N(\mu,\sigma^2)$的区间估计

### 情况一：$\sigma^2$已知，求$\mu$的置信区间

> **枢轴量：** $\dfrac{\bar{X}-\mu}{\sigma/\sqrt{n}}\sim N(0,1)$
>
> **置信区间：** $\left[\bar{X}-z_{\alpha/2}\cdot\dfrac{\sigma}{\sqrt{n}},\;\bar{X}+z_{\alpha/2}\cdot\dfrac{\sigma}{\sqrt{n}}\right]$

### 情况二：$\sigma^2$未知，求$\mu$的置信区间

> **枢轴量：** $\dfrac{\bar{X}-\mu}{S/\sqrt{n}}\sim t(n-1)$
>
> **置信区间：** $\left[\bar{X}-t_{\alpha/2}(n-1)\cdot\dfrac{S}{\sqrt{n}},\;\bar{X}+t_{\alpha/2}(n-1)\cdot\dfrac{S}{\sqrt{n}}\right]$

### 情况三：$\mu$未知，求$\sigma^2$的置信区间

> **枢轴量：** $\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$
>
> **置信区间：** $\left[\dfrac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)},\;\dfrac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right]$

### 情况四：$\mu$已知，求$\sigma^2$的置信区间

> **枢轴量：** $\dfrac{\sum_{i=1}^{n}(X_i-\mu)^2}{\sigma^2}\sim\chi^2(n)$（注意自由度是$n$不是$n-1$！）
>
> **置信区间：** $\left[\dfrac{\sum(X_i-\mu)^2}{\chi^2_{\alpha/2}(n)},\;\dfrac{\sum(X_i-\mu)^2}{\chi^2_{1-\alpha/2}(n)}\right]$

---

## 3.2　两个正态总体的区间估计

### 情况五：$\sigma_1^2,\sigma_2^2$已知，求$\mu_1-\mu_2$的置信区间

> **枢轴量：** $\dfrac{(\bar{X}-\bar{Y})-(\mu_1-\mu_2)}{\sqrt{\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}}}\sim N(0,1)$
>
> **置信区间：** $\left[(\bar{X}-\bar{Y})-z_{\alpha/2}\sqrt{\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}},\;(\bar{X}-\bar{Y})+z_{\alpha/2}\sqrt{\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}}\right]$

### 情况六：$\sigma_1^2=\sigma_2^2=\sigma^2$未知，求$\mu_1-\mu_2$的置信区间

> **枢轴量：** $\dfrac{(\bar{X}-\bar{Y})-(\mu_1-\mu_2)}{S_w\sqrt{\frac{1}{n_1}+\frac{1}{n_2}}}\sim t(n_1+n_2-2)$
>
> 其中$S_w^2=\dfrac{(n_1-1)S_1^2+(n_2-1)S_2^2}{n_1+n_2-2}$（合并样本方差）
>
> **置信区间：** $\left[(\bar{X}-\bar{Y})-t_{\alpha/2}(n_1+n_2-2)\cdot S_w\sqrt{\frac{1}{n_1}+\frac{1}{n_2}},\;(\bar{X}-\bar{Y})+t_{\alpha/2}(n_1+n_2-2)\cdot S_w\sqrt{\frac{1}{n_1}+\frac{1}{n_2}}\right]$

### 情况七：$\sigma_1^2\neq\sigma_2^2$且都未知，大样本下求$\mu_1-\mu_2$的置信区间

> 用$S_1^2,S_2^2$分别代替$\sigma_1^2,\sigma_2^2$，近似用正态分布：
>
> **近似区间：** $\left[(\bar{X}-\bar{Y})-z_{\alpha/2}\sqrt{\frac{S_1^2}{n_1}+\frac{S_2^2}{n_2}},\;(\bar{X}-\bar{Y})+z_{\alpha/2}\sqrt{\frac{S_1^2}{n_1}+\frac{S_2^2}{n_2}}\right]$

### 情况八：$\mu_1,\mu_2$未知，求$\sigma_1^2/\sigma_2^2$的置信区间

> **枢轴量：** $\dfrac{S_1^2}{S_2^2}\cdot\dfrac{\sigma_2^2}{\sigma_1^2}\sim F(n_1-1,n_2-1)$
>
> **置信区间：** $\left[\dfrac{S_1^2}{S_2^2}\cdot\dfrac{1}{F_{\alpha/2}(n_1-1,n_2-1)},\;\dfrac{S_1^2}{S_2^2}\cdot\dfrac{1}{F_{1-\alpha/2}(n_1-1,n_2-1)}\right]$
>
> 利用$F_{1-\alpha/2}(n_1-1,n_2-1)=1/F_{\alpha/2}(n_2-1,n_1-1)$化简：
>
> $\left[\dfrac{S_1^2}{S_2^2}\cdot\dfrac{1}{F_{\alpha/2}(n_1-1,n_2-1)},\;\dfrac{S_1^2}{S_2^2}\cdot F_{\alpha/2}(n_2-1,n_1-1)\right]$

# 第四部分　区间估计速查总表

## 单个正态总体$N(\mu,\sigma^2)$

| 序号 | 条件            | 目标             | 枢轴量分布        | 区间公式要点                                          |
| -- | ------------- | -------------- | ------------ | ----------------------------------------------- |
| ①  | $\sigma^2$已知 | $\mu$          | $N(0,1)$     | $\bar{X}\pm z_{\alpha/2}\cdot\sigma/\sqrt{n}$    |
| ②  | $\sigma^2$未知 | $\mu$          | $t(n-1)$     | $\bar{X}\pm t_{\alpha/2}(n-1)\cdot S/\sqrt{n}$   |
| ③  | $\mu$未知      | $\sigma^2$     | $\chi^2(n-1)$ | $\left[\frac{(n-1)S^2}{\chi^2_{\alpha/2}},\;\frac{(n-1)S^2}{\chi^2_{1-\alpha/2}}\right]$ |
| ④  | $\mu$已知      | $\sigma^2$     | $\chi^2(n)$   | $\left[\frac{\sum(X_i-\mu)^2}{\chi^2_{\alpha/2}(n)},\;\cdots\right]$ |

## 两个正态总体

| 序号 | 条件                              | 目标                       | 枢轴量分布                | 关键公式                          |
| -- | ------------------------------- | ------------------------ | -------------------- | ----------------------------- |
| ⑤  | $\sigma_1^2,\sigma_2^2$已知      | $\mu_1-\mu_2$            | $N(0,1)$             | $(\bar{X}-\bar{Y})\pm z_{\alpha/2}\sqrt{\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}}$ |
| ⑥  | $\sigma_1^2=\sigma_2^2$未知      | $\mu_1-\mu_2$            | $t(n_1+n_2-2)$       | $S_w=$合并标准差                   |

| ⑧  | $\mu_1,\mu_2$未知                | $\sigma_1^2/\sigma_2^2$  | $F(n_1-1,n_2-1)$     | $\frac{S_1^2}{S_2^2}/F_{\alpha/2},\;\frac{S_1^2}{S_2^2}\cdot F_{\alpha/2}'$ |

# 第五部分　考研必记口诀

> **"已知方差用$Z$，未知方差用$t$；
> 一个正态看卡方，两个正态看$F$；
> 枢轴量是关键，分位点别搞错；
> 双侧检验$\alpha/2$，上下对称要记住。"**

## 选错分布的代价

| 本来该用              | 用了            | 后果                        |
| ----------------- | ------------- | ------------------------- |
| $t(n-1)$          | $N(0,1)$      | 区间偏窄，置信度不足                |
| $\chi^2(n-1)$     | $\chi^2(n)$   | 自由度差1，区间虽近但本质错误           |
| $F(n_1-1,n_2-1)$  | $F(n_1,n_2)$  | 同上                        |

> ★ **结论：先判断"单样本还是双样本"→ 再判断"方差已知还是未知"→ 最后回忆分布和自由度。**
