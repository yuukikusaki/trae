# Ch1 · 绪论 —— 复杂度分析（每年1道选择）

## 🎯 必考：时间复杂度分析（7道真题）

### ⚡ 套路速解法

| 循环模式 | 解法 | 示例 |
|----------|------|------|
| `while(x<n) x=2*x` | 对数型：2^t < n → t=O(log n) | 2011 |
| `while(sum<n) sum+=++i` | 累加型：(1+t)t/2 < n → t=O(√n) | 2017, 2019 |
| 递归 `f(n)=f(n-1)+O(1)` | 线性型：递归 n 层 → O(n) | 2012 |
| `for(k*=2) for(j<=n)` | 外层 log n × 内层 n → O(n log n) | 2014 |
| `for(i*=2) for(j<i)` | ⚠️ 陷阱！内层累计为等比 1+2+4... = O(n) | **2022** 🔥 |
| `for(i*i<=n) for(j<=i)` | 内层和 = 1+2+...+√n → O(n) | 2025 |

### 🔥 高频陷阱

```
⚠️ 2022年陷阱题：for(i=1;i<n;i*=2) for(j=0;j<i;j++)
   看似 O(n log n)，实际内层总和 = 1+2+4+...+2^t ≈ 2n-1 = O(n)！
   判断方法：若内层循环上限随外层变量等比增长，求等比数列和。
```

### 📝 大题万能模板

```
// 链表逆置（三指针法）—— 最常考的基础操作
void Reverse(LinkList L) {
    LNode *pre = NULL, *cur = L->next, *next;
    while (cur) {
        next = cur->next;   // ①暂存后继
        cur->next = pre;    // ②反转
        pre = cur;          // ③前移
        cur = next;         // ④前移
    }
    L->next = pre;
}
// O(n), O(1)
```

```
// 快慢指针找中点
LNode *p = L, *q = L;
while (q->next && q->next->next) {
    p = p->next;       // 慢指针走1步
    q = q->next->next; // 快指针走2步
}
// p 指向中点（奇数个）或前半段最后一个（偶数个）
```

# Ch3 · 栈和队列 —— 每年1~2道选择

## 🎯 必考考点

### 出栈序列合法性（最高频，10+道）

```
判断入栈序列 in 能否得到出栈序列 out：
→ 手工模拟：依次读out，若栈顶不等于当前out元素则push，等于则pop
→ 连续出栈的序列必为入栈序的逆序子串
```

| 关键结论 | 真题 |
|---------|------|
| n个元素出栈序列数 = Catalan(n) = 1/(n+1)×C(2n,n) | 2013, 2015 |
| 不允许连续3次出栈 → 出栈序列逆序子串长度<3 | 2010 |
| 已知入栈出栈序求最小栈容量 → 手工模拟记录最大深度 | 2009 |

### 中缀转后缀（2012, 2014, 2024）

```
手算方法：
① 按优先级加括号 
② 运算符移到对应右括号后 
③ 去掉所有括号

机算规则（运算符栈）：
• 遇到 '(' 直接入栈
• 遇到 ')' 弹栈直到 '('
• 当前op优先级 ≤ 栈顶 → 先弹出栈顶再入栈
• 当前op优先级 > 栈顶 → 直接入栈
```

### 循环队列判空判满

```
队空：front == rear
队满：(rear+1) % MAXSIZE == front  （牺牲一个单元）
元素个数：(rear - front + MAXSIZE) % MAXSIZE
```

### 表达式求值（2018）

```
后缀表达式求值：
• 操作数 → 入栈
• 运算符 → 弹出两个，先弹出的是右操作数，后弹出的是左操作数
```

# Ch4 · 串 —— 每3年1道选择

## 🎯 唯一的考点：KMP的next/nextval

### next数组手算步骤

```
① 模式串下标从 1 开始（注意408习惯）
② next[1] = 0, next[2] = 1
③ j≥3: next[j] = P[1..j-1]的最长相等前后缀长度 + 1
   若没有相等前后缀 → next[j] = 1

示例：P = "abaabc"
j=1: 0
j=2: 1
j=3: "ab" → 无 → 1
j=4: "aba" → "a"="a" → 长度1 → 2
j=5: "abaa" → "a"="a" → 长度1 → 2  
j=6: "abaab" → "ab"="ab" → 长度2 → 3
next = [0, 1, 1, 2, 2, 3]
```

### nextval = next的优化

```
当 P[j] == P[next[j]] 时，nextval[j] = nextval[next[j]]
否则 nextval[j] = next[j]
```

| 2019 | KMP匹配过程比较次数计算 |
| 2024 | nextval数组+最大滑动距离 = j - nextval[j] |

# Ch5 · 树与二叉树 —— 分值最高的章 ⭐⭐⭐

## 🎯 二叉树性质（几乎每年1道）

### 必背公式

```
① n0 = n2 + 1  （二叉树中度为0的结点数 = 度为2的结点数 + 1）
② n = n0 + n1 + n2 = 2n0 + n1 - 1
③ 第k层最多 2^(k-1) 个结点
④ 高度h的二叉树最多 2^h - 1 个结点
⑤ 完全二叉树中：最后一个分支结点编号 = ⌊n/2⌋
   叶结点数 = n - ⌊n/2⌋
⑥ n个结点的完全二叉树高度 = ⌈log₂(n+1)⌉ 或 ⌊log₂n⌋ + 1
```

### 完全二叉树判定

```
顺序存储判定（2025新增考点）：
若结点R[i]的有效值，其父结点R[(i-1)/2]必须存在且非空
若某位置为-1（空），则其所有后代也必须为-1
```

| 年份 | 考点 |
|:----:|------|
| 2009 | 完全二叉树第6层8叶结点 → 最多结点数=7层满-缺失 |
| 2011 | 768结点的完全二叉树 → n0=384 |
| 2018 | 满二叉树：n = 2k-1（k为叶结点数） |
| 2020 | 顺序存储所需最少单元 = 满二叉树结点数 |
| 2022 | n0 = n2 + 1 |
| 2025 | 顺序存储合法性判定 |

## 🎯 二叉树遍历（大题第二主战场）

### 三种遍历递归模板

```c
void PreOrder(BiTree T) { if(T){ visit(T); PreOrder(T->lchild); PreOrder(T->rchild); } }
void InOrder(BiTree T)  { if(T){ InOrder(T->lchild); visit(T); InOrder(T->rchild); } }
void PostOrder(BiTree T){ if(T){ PostOrder(T->lchild); PostOrder(T->rchild); visit(T); } }
// 均为 O(n), O(h)
```

### 由遍历序列构造二叉树

```
已知中序 + 先序/后序/层序 → 可唯一确定二叉树
仅知先序+后序 → 不能唯一确定！

构造方法：
1. 先序首/后序尾 → 根结点
2. 中序中根左右分 → 左右子树
3. 递归
```

### 非递归中序遍历（可能手写）

```c
void InOrder2(BiTree T) {
    SqStack S; InitStack(&S);
    BiTree p = T;
    while (p || !StackEmpty(&S)) {
        if (p) { Push(&S, p); p = p->lchild; }  // 一路向左
        else   { Pop(&S, &p); visit(p); p = p->rchild; }
    }
}
```

### 树与森林的遍历对应

```
树 ↔ 二叉树转换规则：左孩子右兄弟
森林的先根遍历 = 对应二叉树的先序遍历
森林的后根遍历 = 对应二叉树的中序遍历
```

## 🎯 二叉排序树 BST

```
性质：左 < 根 < 右（中序有序）
查找：O(h)，最坏退化成链表 O(n)
插入：先查找再插入，始终插在叶结点位置
删除：①叶结点直接删 ②单孩子用孩子替 ③双孩子用右子树最小/左子树最大替
```

## 🎯 平衡二叉树 AVL

```
平衡因子 BF = 左子树高 - 右子树高，|BF| ≤ 1
插入导致失衡时的旋转：
  LL型（左子树的左子树高）→ 右单旋
  RR型（右子树的右子树高）→ 左单旋
  LR型（左子树的右子树高）→ 先左后右双旋
  RL型（右子树的左子树高）→ 先右后左双旋

最小不平衡子树：离插入点最近且|BF|>1的结点为根的子树
```

| 年份 | 考点 |
|:----:|------|
| 2009 | 平衡二叉树判定（|BF|≤1） |
| 2013 | AVL插入后的旋转形态 |
| 2019 | AVL插入/旋转过程 |

## 🎯 哈夫曼树与哈夫曼编码

```
WPL = Σ(叶子权值 × 路径长度)
构造：每次选两个最小权值结点合并（贪心策略）
哈夫曼编码：前缀编码（任何编码不是其他编码的前缀）
```

| 年份 | 考点 |
|:----:|------|
| 2015 | 哈夫曼树WPL计算 |
| 2018 | 哈夫曼编码/前缀编码性质 |

## 🎯 堆（大小根堆）

```
大根堆：每个结点 ≥ 其孩子（根最大）
小根堆：每个结点 ≤ 其孩子（根最小）
建堆：O(n)（从⌊n/2⌋开始向下调整）
插入：放在末尾，向上调整（上滤）O(log n)
删除堆顶：用末尾替换堆顶，向下调整（下滤）O(log n)
```

```
• 检查每个非叶结点是否满足大小关系
```

# Ch6 · 图 —— 大题近年增多 ⭐⭐

## 🎯 图的基本概念

```
所有顶点的度之和 = 2×边数（无向图）
连通图最少边数 = n-1（生成树）
保证n顶点图在任何情况下连通的最少边数 = C(n-1,2) + 1
```

| 年份 | 考点 |
|:----:|------|
| 2009 | 度之和为偶数 |
| 2010 | 保证7顶点连通最少边数=16 |
| 2017 | 已知度数分布求最少顶点数 |
| 2022 | 边数与连通性的关系 |

## 🎯 图的存储

```
邻接矩阵：O(n²)空间，适合稠密图
邻接表：O(n+e)空间，适合稀疏图
```

## 🎯 图的遍历

```
DFS：递归/栈，类似树的先序。邻接表 O(n+e)，邻接矩阵 O(n²)
BFS：队列，类似树的层序。邻接表 O(n+e)，邻接矩阵 O(n²)

DFS修改版（输出在递归退出前）→ 得到逆拓扑序列（2020真题）
```

## 🎯 最小生成树

```
Prim：从点出发，选最小边扩展 → O(n²) 邻接矩阵
Kruskal：从边出发，选最小边不构成回路 → O(e log e)

MST代价唯一，树形可能不唯一（边权相等时）
当所有边权互不相同时，MST唯一
```

| 年份 | 考点 |
|:----:|------|
| 2012 | MST性质判断 |
| 2015 | Kruskal选边过程 |
| 2017 | Prim过程+唯一性条件 |
| 2018 | Kruskal实际应用 |
| 2020 | Kruskal选边顺序 |

## 🎯 最短路径

**Dijkstra（单源最短路径）：**
```
步骤：每次从未确定顶点中选dist最小的加入集合S，更新邻接点dist
不适用于负权边
```

**Floyd（多源最短路径）：**
```
核心：dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
O(n³)，三层循环，k在最外层
```

## 🎯 拓扑排序

```
步骤：每次选入度为0的顶点输出，删除其所有出边，重复
存在拓扑序列 ⇔ 图为DAG（无环）
拓扑序列可能不唯一

大题模式：判断是否存在唯一拓扑序列（2024真题）
思路：每次选入度为0的顶点，若始终只有一个可选 → 唯一
```

| 年份 | 考点 |
|:----:|------|
| 2010 | 拓扑序列个数 |
| 2012 | 拓扑序列与邻接矩阵关系 |
| 2013 | AOE网关键路径缩短 |

## 🎯 关键路径（AOE网）

```
ve(k)：事件最早发生时间，正向递推，取max
vl(k)：事件最迟发生时间，反向递推，取min
e(i)：活动最早开始 = ve(起点)
l(i)：活动最迟开始 = vl(终点) - 活动时间
l(i) - e(i) = 0 → 关键活动

只有缩短所有关键路径共有的活动才能缩短工期
```

# Ch7 · 查找

## 🎯 二分查找

```
mid = lo + (hi - lo) / 2  （防溢出，2020考过）
最多比较次数 = ⌊log₂n⌋ + 1 = 判定树高度
判定树是平衡二叉树 → 左右子树结点数差≤1

适用条件：有序 + 顺序存储（随机存取）！
链表不能直接二分查找（2024真题）
```

## 🎯 B树与B+树

### B树核心公式

```
m阶B树：
① 每个结点最多 m-1 个关键字，最多 m 棵子树
② 根结点最少 1 个关键字（非叶时最少 2 棵子树）
③ 非根非叶最少 ⌈m/2⌉-1 个关键字，最少 ⌈m/2⌉ 棵子树
④ 所有叶结点在同一层（不带信息）

n个关键字的m阶B树：
最大高度 h_max = 1 + log_⌈m/2⌉((n+1)/2)
最小高度 h_min = ⌈log_m(n+1)⌉
```

### B树插入与删除

```
插入：找到叶结点插入 → 若关键字数 > m-1 则分裂（中间关键字上升）
删除：①在终端结点 → 直接删，不够则借兄弟或合并
      ②在非终端结点 → 用前驱/后继替换，转①
```

### B+树 vs B树

```
B+树：所有关键字在叶结点，叶结点链表相连
     非叶结点仅做索引，不存数据指针
B树：每个结点既存关键字也存数据指针
```

## 🎯 哈希表

```
装填因子 α = n/m（n=元素数，m=表长）
ASL成功/失败计算：
  • 线性探测：逐个向后找空位
  • 链地址法：同义词链表

哈希表ASL仅取决于α，与n无关！（2020真题）
```

## 🔥 408最高频考点 Top 5

### 1. 快速排序（10+道真题）

```
关键特征：
• 每趟确定一个元素的最终位置（枢轴）
• 空间复杂度 O(log n)（递归栈），不是 O(1)！
• 最坏 O(n²)：初始有序或逆序时
• 判定「第k趟结果」：第k趟后至少有k个元素处于最终位置
  → 若第2趟，不少于2个元素在最终位置

真题套路：给一个序列，问是否可能是第N趟快排结果
解法：检查有多少个元素已处于最终位置（和最终排序序列表对比）
```

### 2. 排序稳定性判断 🔥

```
稳定的排序：直接插入、冒泡、归并、基数
不稳定的排序：希尔、快速、选择、堆排序

408最爱考：「下列排序算法中稳定的是___」
          「下列稳定排序是___」
```

### 3. 空间复杂度陷阱

```
O(1)：直接插入、折半插入、希尔、冒泡、选择、堆排序
O(log n)：快速排序（递归栈！不是O(1)）
O(n)：归并排序（辅助数组）
```

### 4. 建堆复杂度

```
⚠️ 建堆是 O(n)，不是 O(n log n)！
「筛选法」建堆：从⌊n/2⌋开始向下调整
```

### 5. 希尔排序的增量

```
组内用直接插入排序
增量选取：常见 n/2, n/4... 或其他递减序列
真题考法：给序列和中间结果，推测增量（2014, 2018）
```

```
① 基本设计思想（40%过程分！）

   → 关键步骤加注释

③ 复杂度分析（20%）
   → 时间复杂度：O(?) 
   → 空间复杂度：O(?)
```

```
✅ 思路对 → 过程分（可以先写注释描述思路）
```
