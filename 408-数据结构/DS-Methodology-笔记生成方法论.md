# 📐 408 数据结构笔记生成方法论

> 🎯 **目标**：这套方法可以复用到 408 其他科目（计组、OS、计算机网络），也可以用于任何需要"教材+真题+代码"三位一体学习的场景。

---

## 一、核心思路

```
教材知识点 ──→ 真题考点映射 ──→ 代码验证 ──→ 笔记输出
   │               │               │
   ▼               ▼               ▼
 全面扫描        精准聚焦        动手验证
```

### 1.1 三阶段流程

| 阶段 | 做什么 | 产出 |
|:----:|--------|------|
| **Phase 1：教材提取** | PDF → txt → 对照笔记找缺失 | 知识点 checklist |
| **Phase 2：真题注入** | 搜索历年真题 → 按tag分类 → 回链到笔记 | 真题分类表 |
| **Phase 3：代码+力扣** | 每章挑10-20道力扣 → 标注与408差异 | 刷题路线 |

## 二、Phase 1：教材内容提取与对比

### 2.1 PDF提取脚本（模板）

```python
# 提取PDF文本的通用脚本
import pdfplumber
import os

def extract_pdf_to_text(pdf_dir, output_dir):
    """
    批量提取PDF教材文本，按章节保存为txt
    用法：修改 pdf_dir 指向你的教材文件夹
    """
    os.makedirs(output_dir, exist_ok=True)

    for pdf_name in os.listdir(pdf_dir):
        if not pdf_name.endswith('.pdf'):
            continue
        pdf_path = os.path.join(pdf_dir, pdf_name)
        txt_path = os.path.join(output_dir, pdf_name.replace('.pdf', '.txt'))

        with pdfplumber.open(pdf_path) as pdf:
            full_text = []
            for i, page in enumerate(pdf.pages):
                text = page.extract_text()
                if text:
                    full_text.append(f"--- 第{i+1}页 ---\n{text}")

            with open(txt_path, 'w', encoding='utf-8') as f:
                f.write('\n'.join(full_text))

        print(f"✅ {pdf_name} → {txt_path}")

extract_pdf_to_text("D:/教材目录", "./pdf_text")
```

### 2.2 关键对比点

与教材对照时，重点检查以下内容：

| 检查项 | 说明 |
|--------|------|
| **被跳过的节** | 教材有但笔记遗漏的完整小节（如"数组与特殊矩阵"） |
| **公式/定理** | 性质、推导过程、重要结论（如 n0=n2+1） |
| **复杂度标记** | 每个算法的时间/空间复杂度是否标注 |
| **教材上的例题** | 教材中的精选习题是否有解题过程 |
| **特殊存储结构** | 十字链表、三叉链表、逆邻接表等变体结构 |
| **边界条件** | 判空判满条件、递归出口、数组下标起始等 |

## 四、Phase 3：代码验证与力扣对标

### 4.1 力扣题选择策略

| 标准 | 说明 |
|------|------|
| **与408考点高度重合** | 优先选经典题（如链表逆置、二叉树遍历、二分查找） |
| **覆盖核心操作** | 每个数据结构保证覆盖"增删改查"全生命周期 |
| **按难度分梯队** | 简单→巩固、中等→实战、困难→拓展 |
| **标注408差异** | 头结点有无、下标起始、函数签名、空间复杂度要求 |

### 4.2 力扣搜索技巧

```
在力扣搜索栏输入：
- "链表" + "反转" → 206
- "二叉树" + "遍历" → 144/94/145
- "拓扑排序" → 207/210
- "最短路径" → 743
```

### 4.3 408 vs 力扣差异对比模板

| 方面 | 力扣（工程风格） | 408（考试风格） |
|------|-----------------|-----------------|
| 头结点 | 根据题意 | 默认带头结点 |
| 下标起始 | 0-based | 注意1-based场景 |
| 函数签名 | 返回新头/值 | 通常void修改原结构 |
| 空间要求 | 通常宽裕 | 常要求O(1)原地 |
| 复杂度标注 | 不强制 | 函数后必须标注 O(?) 和 O(?) |

## 六、跨科目复用清单

当你用这套方法做下一个科目时，按以下清单执行：

### ✅ 准备工作
- [ ] 收集该科目的PDF教材（或实体书）
- [ ] 安装 `pdfplumber`（`pip install pdfplumber`）
- [ ] 创建科目的 Obsidian Vault / 文件夹

### ✅ Phase 1：提取与对比（约2小时）
- [ ] 运行 PDF 提取脚本，批量生成 txt 文本
- [ ] 创建或找到现有基础笔记
- [ ] 逐章阅读教材txt，对照笔记找出缺失内容
- [ ] 标记缺失项（公式、定义、例题、边界条件）

### ✅ Phase 2：真题注入（约3小时）
- [ ] 使用 WebSearch 搜索历年真题
- [ ] 创建 `[科目]-408真题分类汇总.md`
- [ ] 按章节+tag分类录入真题
- [ ] 在笔记末尾追加真题年份表
- [ ] 为每道真题添加 [[wiki链接]] 到对应笔记

### ✅ Phase 3：代码+力扣（约2小时/章）
- [ ] 在力扣搜索对应数据结构的经典题
- [ ] 每章挑选 5-15 题，标注难度和考点关联
- [ ] 添加"408 vs 力扣"差异对比表
- [ ] 设计分阶段刷题路线

### ✅ 最终检查
- [ ] 所有 [[wiki链接]] 是否可点击
- [ ] 所有tag是否在真题文件中被覆盖
- [ ] 大题模板是否覆盖近10年考点
- [ ] 复杂度速查表是否完整
