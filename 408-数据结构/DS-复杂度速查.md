### 树与二叉树

| 操作 | 二叉树 | BST | AVL | 堆 |
|------|--------|-----|-----|-----|
| 查找 | O(n) | O(h) | O(log n) | O(n) |
| 插入 | — | O(h) | O(log n) | O(log n) |
| 删除 | — | O(h) | O(log n) | O(log n) |

> h = 树高，BST 最坏退化成链表 h=n → O(n)

### 查找

| 算法 | 时间复杂度 | 前提 |
|------|-----------|------|
| 顺序查找 | **O(n)** | 无 |
| 二分查找 | **O(log n)** | 有序 + 随机存取 |
| BST | O(h), 最坏 O(n) | — |
| AVL | **O(log n)** | 平衡 |
| B 树 | **O(log_m n)** | — |
| 哈希表 | **O(1)** 平均 | 好的哈希函数 + 低装填因子 |

## 空间复杂度速记

| 空间 | 算法/结构 |
|------|----------|
| O(1) 原地 | 顺序表操作、链表操作、栈、队列、冒泡/插入/选择/希尔/堆排序 |
| O(log n) | **快速排序**（递归栈）、二叉树递归遍历（栈深度=树高） |
| O(n) | 归并排序（辅助数组）、哈希表、邻接表 |
| O(n²) | 邻接矩阵 |

## 🔥 408 高频陷阱

| 陷阱 | 正解 |
|------|------|
| 快排空间复杂度 | **O(log n)**，不是 O(1)——递归需要栈 |
| 堆排序稳定性 | **不稳定**——建堆过程破坏相对顺序 |
| 建堆复杂度 | **O(n)**，不是 O(n log n) |
| 希尔排序稳定性 | **不稳定**——跳跃式交换 |
| 归并排序空间 | **O(n)**，需要辅助数组 |
| BST 最坏情况 | 退化成链表 → O(n)，不是 O(log n) |
| 折半插入排序 | 比较次数 O(n log n)，但移动次数仍 O(n²) |
