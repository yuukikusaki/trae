# DS-Ch6-图

> [[DS-MOC-数据结构总览|MOC]] | 上一章：[[DS-Ch5-树与二叉树]] | 下一章：[[DS-Ch7-查找]]

## 1. 基本概念

| 术语 | 核心 |
|------|------|
| 无向完全图 | n(n-1)/2 条边 |
| 有向完全图 | n(n-1) 条边 |
| 连通图 | 无向图，任意两点有路径 |
| 强连通图 | 有向图，任意两点双向可达 |
| 生成树 | 含全部 n 个顶点的极小连通子图，n-1 条边 |

### 度与边数（必考）

- 无向图：$\sum \deg = 2|E|$ → 度之和必为偶数 → **2009真题**
- 有向图：$\sum \text{入度} = \sum \text{出度} = |E|$

### 连通性临界条件（高频）

- 连通图最少边数 = n-1（生成树）
- **保证无论如何都连通的最少边数** = $C_{n-1}^2 + 1 = \frac{(n-1)(n-2)}{2} + 1$ → **2010真题**
- n 个顶点、边数 < n-1 → 一定不连通 → **2022真题**

> 真题：2009(T15)、2010(T16)、2017(T17)、2022(T18)

## 2. 图的存储

| 存储方式 | 空间 | 判边 | 遍历邻接点 | 适用 |
|----------|------|------|-----------|------|
| 邻接矩阵 | $O(n^2)$ | $O(1)$ | $O(n)$ | 稠密图 |
| 邻接表 | $O(n+e)$ | $O(e/n)$ | $O(\text{出度})$ | 稀疏图 |

### 邻接矩阵

- 无向图对称，有向图不一定对称
- 有向图：行 = 出度，列 = 入度，度 = 行列非零元素之和 → **2013真题**

### 邻接表

- 有向图求入度需遍历全部边表，若要快速求入度 → 逆邻接表
- 邻接多重表（无向图）：每条边只存一个结点，适合频繁边操作 → **2024真题**

> 真题：2013(T19)、2024(T20)

## 3. 图的遍历

### DFS vs BFS

| | DFS | BFS |
|------|------|------|
| 数据结构 | 栈（递归） | 队列 |
| 类似 | 树的先序 | 树的层序 |
| 邻接矩阵复杂度 | $O(n^2)$ | $O(n^2)$ |
| 邻接表复杂度 | $O(n+e)$ | $O(n+e)$ |

### 关键结论

- **调用 DFS/BFS 的次数 = 连通分量个数**
- BFS 求无权图最短路径：BFS 按层访问，层数 = 最短路径边数
- DFS 回溯时输出顶点 → 逆拓扑序列 → **2020真题**

## 4. 最小生成树（MST）

### Prim

- 策略：从点出发，每次选连接 U 和 V-U 的最小权边
- 复杂度：$O(n^2)$ → 适合稠密图

### Kruskal

- 策略：所有边排序，依次选最小且不构成回路的边
- 复杂度：$O(e \log e)$（排序主导） → 适合稀疏图

### 唯一性条件

- 所有边权互不相同 → MST 唯一
- 有权值相等的边 → MST 可能不唯一，但代价唯一

> 真题：2012、2015(Kruskal手算)、2017(Prim唯一性)、2018(Kruskal)、2020

## 5. 最短路径

### Dijkstra（单源，贪心）

- 每次选 dist 最小且未确定的顶点加入 S，更新其邻接点
- **不适用于负权边**（已确定顶点可能被负权边再次缩短）
- 复杂度：$O(n^2)$

**手算模板**：每次选择 → 加入 S → 松弛更新，共 n-1 轮

### Floyd（多源，动态规划）

- 核心：$dist[i][j] = \min(dist[i][j],\ dist[i][k] + dist[k][j])$
- k 循环在最外层，三层循环 → $O(n^3)$
- 允许负权边，不允许负权回路
- 可检测负权回路：若 $dist[i][i] < 0$ 则存在

### 对比

| 算法 | 范围 | 时间 | 负权边 |
|------|------|------|:---:|
| Dijkstra | 单源 | $O(n^2)$ | ❌ |
| Floyd | 所有顶点对 | $O(n^3)$ | ✅ |

> 真题：2012(Dijkstra手算)、2020(Floyd)

## 6. 拓扑排序（AOV网）

### 步骤
1. 计算所有顶点入度
2. 入度为 0 的入栈/队列
3. 输出 → 邻接点入度减 1 → 变为 0 则入栈/队列
4. 重复直到栈空

### 考点

- 存在拓扑序列 ⇔ 图为 DAG（无环）
- 若最后输出数 < n → 图中有回路
- 拓扑序列**通常不唯一**
- 用栈 → 逆偏序输出；用队列 → 偏序输出
- **判断唯一性**（2024大题）：每次入度为 0 的顶点始终只有 1 个 → 唯一

> 真题：2010、2012、2013、2014、2016、2018-2021（选择），**2024（大题）**

## 7. 关键路径（AOE网）

### 四个量

| 量 | 含义 | 计算方向 |
|----|------|----------|
| $ve(k)$ | 事件 k **最早**发生 | 源点→汇点，**取 max** |
| $vl(k)$ | 事件 k **最迟**发生 | 汇点→源点，**取 min** |
| $e(i)$ | 活动最早开始 = $ve(\text{弧尾})$ | — |
| $l(i)$ | 活动最迟开始 = $vl(\text{弧头}) - 权$ | — |

**关键活动**：$e(i) = l(i)$（时间余量为 0）

### 手算步骤

```
① ve：源点 ve=0，正向递推，前驱 ve + 边权 → 取 max
② vl：汇点 vl=ve，反向递推，后继 vl - 边权 → 取 min
③ e(i) = ve(弧尾), l(i) = vl(弧头) - 权
④ 关键活动 = { i | e(i) = l(i) }
```

### 考点

- 关键路径可能有多条，缩短**公共关键活动**才有效缩短工期
- 缩短某关键活动后可能使关键路径改变，需重新计算
- $ve$ 取 **max**，$vl$ 取 **min**（方向记反全错）

> 真题：2013(AOE缩短工期)、2019(ve/vl计算)

## 9. 易错点速查

| # | 陷阱 | 正解 |
|:--:|------|------|
| 1 | 度之和 = 边数 | 度之和 = **2×边数**（无向图） |
| 2 | 连通最少边数 = n-1？ | 那是"可以是"，"保证任何情况"需要 $C_{n-1}^2+1$ |
| 3 | Dijkstra 可用负权边 | **不能**，已确定顶点不可再被缩短 |
| 4 | Floyd 的 k 循环位置 | k 必须在**最外层** |
| 5 | ve 取 min，vl 取 max | ve 取 **max**，vl 取 **min**，方向相反 |
| 6 | MST 一定唯一 | 仅当边权**互不相同**时才唯一 |
| 7 | 邻接表求有向图入度 O(1) | 需遍历全部边表，**O(n+e)** |
| 8 | BFS 可求任意图最短路径 | 仅**无权图**（或边权全相等） |
| 9 | 拓扑序列一定唯一 | 通常**不唯一**，入度 0 顶点始终唯一时例外 |
