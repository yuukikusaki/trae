还算简单，了解每种排序的运作方式就行
1. 插入排序
	1. 了解希尔的运行机制
2. 交换排序
	1. 了解快排的运行机制
3. 选择排序
	1. 大小根堆（$2i,2i+1$，上升对比一次，下坠要比较两个孩子，所以最多两次)
		1. 插入一路上升
		2. 删除，先用最底部替换，然后下坠
4. 归并、基数、计数
	1. 2路归并的用法
		- 已知路数 m、初始归并段 n；
		- 求 r=(n−1)mod(m−1)；
		- r=0，虚段 k=0；否则 k=(m−1)−r；
		- 构造最佳归并树时，参与排序的总段数 = n+k。
	2. 基数就是数字从个位开始

| 算法      | 最好         | 平均         | 最坏         | 空间       | 稳定  |
| ------- | ---------- | ---------- | ---------- | -------- | :-: |
| 基数排序    | O(d(n+r))  | O(d(n+r))  | O(d(n+r))  | O(n+r)   |  ✅  |
| 归并排序    | O(n log n) | O(n log n) | O(n log n) | O(n)     |  ✅  |
| **堆排序** | O(n log n) | O(n log n) | O(n log n) | O(1)     |  ❌  |
| 快速排序    | O(n log n) | O(n log n) | O(n²)      | O(log n) |  ❌  |
| 希尔排序    | —          | O(n^1.3)   | O(n²)      | O(1)     |  ❌  |
| 直接插入    | O(n)       | O(n²)      | O(n²)      | O(1)     |  ✅  |
| 冒泡排序    | O(n)       | O(n²)      | O(n²)      | O(1)     |  ✅  |
| 选择排序    | O(n²)      | O(n²)      | O(n²)      | O(1)     |  ❌  |
