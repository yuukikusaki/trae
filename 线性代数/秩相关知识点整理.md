# 秩 —— 考研线性代数知识点整理

> 秩是线性代数中贯穿始终的核心概念——它既是矩阵的"骨骼"，也是连接方程组、向量空间、特征值各章的枢纽。秩的结论众多且密集，本文覆盖考研范围内所有秩相关的定义、性质、不等式和解题技巧。

---

## 一、秩的定义

### 1.1 矩阵的秩

设 $A$ 为 $m \times n$ 矩阵。矩阵的秩有三种等价定义：

| 定义方式 | 内容 |
|----------|------|
| **行/列秩定义** | $A$ 的行向量组的秩 = $A$ 的列向量组的秩 = $r(A)$ |
| **子式定义** | $A$ 中非零子式的最高阶数（若 $A$ 有一个 $r$ 阶子式不为零，而所有 $r+1$ 阶子式全为零，则 $r(A) = r$） |
| **初等变换定义** | $A$ 经过初等行变换化为行阶梯形矩阵后，非零行的行数 |

> 三个定义完全等价。**行秩 = 列秩 = 子式秩** 是线性代数中最深刻的结论之一。

### 1.2 向量组的秩

设 $\alpha_1, \alpha_2, \dots, \alpha_s$ 为一组向量，其**极大线性无关组**所含向量的个数称为该向量组的**秩**，记为 $r(\alpha_1, \dots, \alpha_s)$。

- 以这些向量为列构成矩阵 $A = [\alpha_1, \dots, \alpha_s]$，则 $r(A) = r(\alpha_1, \dots, \alpha_s)$。
- 向量组线性无关 $\iff$ 秩等于向量的个数。

### 1.3 满秩与降秩

| 术语 | 条件 | 等价说法 |
|------|------|----------|
| **行满秩** | $r(A) = m$（$m \le n$） | $A$ 的行向量组线性无关 |
| **列满秩** | $r(A) = n$（$m \ge n$） | $A$ 的列向量组线性无关 |
| **满秩方阵** | $r(A) = n$ | $A$ 可逆，$|A| \neq 0$ |
| **降秩方阵** | $r(A) < n$ | $A$ 不可逆，$|A| = 0$ |

## 二、秩的计算

### 2.1 初等变换法（最通用）

将矩阵通过**初等行变换**化为行阶梯形，非零行的行数即为秩。

```
A ──初等行变换──→ 行阶梯形矩阵 U，r(A) = U 中非零行数
```

也可进一步化为行最简形，但计算秩只需到行阶梯形即可。

### 2.2 子式法（适用于小矩阵）

寻找一个 $r$ 阶子式非零，且所有 $r+1$ 阶子式全为零，则 $r(A) = r$。

实际做题中，$2 \times 2$ 和 $3 \times 3$ 矩阵常用子式法快速判断。

### 2.3 定义法

借助秩的性质/不等式推算出秩的准确值（常见于含参数的矩阵、证明题）。

## 三、秩的基本性质

### 3.1 运算性质

| 编号 | 性质 | 备注 |
|------|------|------|
| ① | $r(A) = r(A^T)$ | 转置不改变秩 |
| ② | $r(kA) = r(A)$（$k \neq 0$） | 非零数乘不改变秩 |
| ③ | $r(PAQ) = r(A)$（$P, Q$ 可逆） | 左乘/右乘可逆矩阵不改变秩 |
| ④ | 初等变换不改变矩阵的秩 | ② 的特例 |

### 3.2 加法不等式

$$r(A + B) \le r(A) + r(B)$$

### 3.3 乘法不等式（Sylvester 不等式）

$$r(A) + r(B) - n \le r(AB) \le \min\{r(A), r(B)\}$$

其中 $A$ 为 $m \times n$ 矩阵，$B$ 为 $n \times s$ 矩阵，$n$ 为 $A$ 的列数（$B$ 的行数）。

**两个重要特例**：

| 条件 | 结论 |
|------|------|
| $AB = O$ | $r(A) + r(B) \le n$ |
| $A$ 列满秩（$r(A) = n$） | $r(AB) = r(B)$ |
| $B$ 行满秩（$r(B) = n$） | $r(AB) = r(A)$ |

### 3.4 分块矩阵的秩

| 编号 | 性质 |
|------|------|
| ⑤ | $r\begin{pmatrix} A & O \\ O & B \end{pmatrix} = r(A) + r(B)$ |
| ⑥ | $r(A) + r(B) \le r\begin{pmatrix} A & C \\ O & B \end{pmatrix} \le r(A) + r(B) + r(C)$ |
| ⑦ | $\max\{r(A), r(B)\} \le r(A, B) \le r(A) + r(B)$ |

## 四、秩的重要不等式（高频考点）

以下不等式是考研中推导秩的范围和关系的核心工具：

### 4.1 基础不等式

$$0 \le r(A) \le \min\{m, n\}$$

$$r(A) = 0 \iff A = O$$

### 4.2 经典不等式汇总

| 编号 | 不等式 | 适用条件 |
|------|--------|----------|
| S1 | $r(AB) \le \min\{r(A), r(B)\}$ | $A_{m \times n}, B_{n \times s}$ |
| S2 | $r(AB) \ge r(A) + r(B) - n$ | $A_{m \times n}, B_{n \times s}$（Sylvester） |
| S3 | $AB = O \Rightarrow r(A) + r(B) \le n$ | $A_{m \times n}, B_{n \times s}$ |
| S4 | $r(A + B) \le r(A) + r(B)$ | 同型矩阵 |
| S5 | $r(A - B) \ge |r(A) - r(B)|$ | 同型矩阵 |
| S6 | 若 $P, Q$ 可逆，则 $r(PAQ) = r(A)$ | — |
| S7 | $r(A^T A) = r(A A^T) = r(A)$ | 实矩阵 |
| S8 | $r(A^*) = \begin{cases} n, & r(A) = n \\ 1, & r(A) = n-1 \\ 0, & r(A) < n-1 \end{cases}$ | $A$ 为 $n$ 阶方阵，$A^*$ 为伴随矩阵 |

### 4.3 等价关系的秩条件

| 关系 | 秩条件 | 说明 |
|------|--------|------|
| $A$ 与 $B$ **等价** | $r(A) = r(B)$ | 等价即同秩（充要条件） |
| $A$ 与 $B$ **相似** | $r(A) = r(B)$ | 相似必然同秩（但同秩不一定相似） |
| $A$ 与 $B$ **合同**（实对称） | $r(A) = r(B)$，且正负惯性指数相同 | 合同需要惯性指数一致 |

## 五、秩与线性方程组

### 5.1 解的存在性

设 $A$ 为 $m \times n$ 矩阵，$b$ 为 $m$ 维列向量：

| 情况 | 秩条件 | 几何解释 |
|------|--------|----------|
| **无解** | $r(A) < r(A, b)$ | $b$ 不在 $A$ 的列空间中 |
| **有唯一解** | $r(A) = r(A, b) = n$ | $b$ 可被列向量唯一表示 |
| **有无穷多解** | $r(A) = r(A, b) < n$ | $b$ 可被列向量表示，但列向量线性相关 |

### 5.2 齐次方程组 $Ax = 0$

设 $A$ 为 $m \times n$ 矩阵：

$$解空间的维数 = n - r(A)$$

即**基础解系所含向量的个数 = 未知数个数 − 系数矩阵的秩**。

| $r(A)$ 的值 | 解的情况 |
|-------------|----------|
| $r(A) = n$ | 仅有零解 |
| $r(A) < n$ | 有非零解（无穷多解） |

### 5.3 非齐次方程组 $Ax = b$

通解结构：**特解 + 齐次通解**

$$x = x^* + k_1 \xi_1 + \cdots + k_{n-r} \xi_{n-r}$$

其中 $r = r(A)$，$\{\xi_i\}$ 为 $Ax = 0$ 的基础解系，自由未知量个数为 $n - r$。

## 六、秩与其他核心概念的关系网

### 6.1 秩与行列式

| 条件 | 结论 |
|------|------|
| $|A| \neq 0$ | $r(A) = n$（$A$ 满秩 / 可逆 / 非奇异） |
| $|A| = 0$ | $r(A) < n$（$A$ 降秩 / 不可逆 / 奇异） |
| $A$ 有 $r$ 阶非零子式，所有 $r+1$ 阶子式为零 | $r(A) = r$ |

### 6.2 秩与特征值

| 结论 | 说明 |
|------|------|
| $r(A) = 0 \iff$ 所有特征值全为 $0$（零矩阵情形） | 仅 $O$ 的秩为 $0$ |
| $r(A) = n - s$，其中 $s$ 为零特征值的**几何重数**（即齐次方程 $Ax = 0$ 的解空间维数） | $\lambda = 0$ 时，$r(A) = r(0E - A) = n - \dim \ker(A)$ |
| 若 $A$ 可对角化，则非零特征值的个数（代数重数计）$\ge r(A)$ | 非零特征值的代数重数之和即为非零特征值的总重数 |
| 秩为 $1$ 的矩阵特征值：一个 $\operatorname{tr}(A)$，其余 $n-1$ 个为 $0$ | $A = \alpha \beta^T$ 型 |

### 6.3 秩与向量空间

设 $A$ 为 $m \times n$ 矩阵：

| 概念 | 与秩的关系 |
|------|------------|
| 列空间 $\operatorname{Col}(A)$ 的维数 | $\dim \operatorname{Col}(A) = r(A)$ |
| 行空间 $\operatorname{Row}(A)$ 的维数 | $\dim \operatorname{Row}(A) = r(A)$ |
| 零空间（核空间）$\ker(A)$ 的维数 | $\dim \ker(A) = n - r(A)$ |
| 维数公式 | $r(A) + \dim \ker(A) = n$ |

> 这就是线性代数中著名的**秩-零化度定理**（Rank-Nullity Theorem）。

### 6.4 秩与线性表示、线性相关性

| 命题 | 等价秩条件 |
|------|------------|
| 向量组 $\alpha_1, \dots, \alpha_s$ 线性无关 | $r(\alpha_1, \dots, \alpha_s) = s$ |
| 向量 $\beta$ 可由 $\alpha_1, \dots, \alpha_s$ 线性表示 | $r(\alpha_1, \dots, \alpha_s) = r(\alpha_1, \dots, \alpha_s, \beta)$ |
| 两向量组等价 | 秩相等，且 $\{\alpha_i\}$ 可被 $\{\beta_j\}$ 表示（或反之） |
| $\alpha_1, \dots, \alpha_s$ 为极大无关组 | 线性无关 + 向量组中任一向量的秩 = $s$ |

## 七、秩的特殊结论速查

### 7.1 方阵的秩与可逆性（等价命题）

对于 $n$ 阶方阵 $A$，以下命题等价：

1. $A$ 可逆
2. $|A| \neq 0$
3. $r(A) = n$
4. $A$ 的行（列）向量组线性无关
5. $Ax = 0$ 仅有零解
6. $Ax = b$ 有唯一解（对任意 $b$）
7. $A$ 的特征值全不为 $0$
8. $A$ 可通过初等行变换化为 $E$

### 7.2 伴随矩阵的秩（重要）

设 $A$ 为 $n$ 阶方阵（$n \ge 2$），$A^*$ 为其伴随矩阵：

$$r(A^*) = \begin{cases}
n, & r(A) = n \\
1, & r(A) = n - 1 \\
0, & r(A) \le n - 2
\end{cases}$$

此结论在求伴随矩阵秩、以及配合 $AA^* = |A|E$ 解题时反复使用。

### 7.3 $A^T A$ 与 $A A^T$ 的秩

对于任意实矩阵 $A$：

$$r(A^T A) = r(A A^T) = r(A)$$

此性质在最小二乘法和二次型问题中尤为重要。

### 7.4 幂等矩阵的秩

若 $A^2 = A$（幂等矩阵），则：

$$r(A) + r(E - A) = n$$

进而 $A$ 可对角化，且特征值仅为 $0$ 和 $1$。

## 八、秩不等式证明的常用思路

考研中秩相关的证明题通常围绕以下几条路线展开：

| 思路 | 核心工具 | 典型场景 |
|------|----------|----------|
| **方程组语言** | $Ax = 0$ 解空间的维数 = $n - r(A)$ | 证明 $AB = O \Rightarrow r(A) + r(B) \le n$ |
| **向量组语言** | 极大无关组的扩充与表示 | 证明 $r(A + B) \le r(A) + r(B)$ |
| **分块矩阵** | 构造分块矩阵，利用初等变换 | 证明 Sylvester 不等式 |
| **线性映射** | 核与像的维数公式 $\dim \ker + \dim \operatorname{Im} = n$ | 抽象矩阵秩的结论 |
| **初等变换** | 通过初等变换将矩阵化为简单形式 | 任意矩阵的秩计算 |

## 九、考研常见题型与注意点

1. **求具体矩阵的秩**：初等行变换化为行阶梯形，数非零行——计算要稳、准；
2. **含参数矩阵的秩讨论**：对参数分类讨论，注意不同参数值下阶梯形的变化；
3. **利用秩讨论方程组解的情况**：$r(A) = r(A, b)$ 判定有解，$n - r(A)$ 定自由未知量个数；
4. **秩不等式的证明**：选择题和证明题中的高频考点，牢记 $r(AB) \le \min\{r(A), r(B)\}$ 和 $AB = O \Rightarrow r(A) + r(B) \le n$；
5. **等价 / 相似 / 合同的秩判定**：等价只需同秩；相似和合同还需要额外条件（特征值或惯性指数）；
6. **伴随矩阵的秩**：直接套用三段式结论；
7. **秩 = 1 的矩阵**：可写为 $\alpha \beta^T$，特征值一个为 $\beta^T \alpha$（迹），其余为零——选择填空题的"快车道"。
