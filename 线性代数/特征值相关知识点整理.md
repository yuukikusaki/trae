# 特征值与特征向量 —— 考研线性代数核心串讲

> 特征值、相似对角化、二次型三者是考研线代的"最后一块高地"。本文以特征值为线索，将相似、正交变换、合同变换、二次型标准型与规范型串联起来，梳理它们之间的内在联系。

---

## 一、特征值与特征向量

### 1.1 定义

设 $A$ 为 $n$ 阶方阵，若存在数 $\lambda$ 和非零列向量 $x$，使得

$$Ax = \lambda x$$

则称 $\lambda$ 为 $A$ 的一个**特征值**，$x$ 为 $A$ 的属于 $\lambda$ 的一个**特征向量**。

### 1.2 特征方程

将 $Ax = \lambda x$ 改写为 $(\lambda E - A)x = 0$，若要有非零解，系数矩阵必须不满秩：

$$|\lambda E - A| = 0$$

该方程称为**特征方程**，$f(\lambda) = |\lambda E - A|$ 称为**特征多项式**。

### 1.3 计算步骤

1. 计算特征多项式 $|\lambda E - A|$，求特征方程的全部根，即全部特征值；
2. 对每个特征值 $\lambda_i$，解齐次线性方程组 $(\lambda_i E - A)x = 0$，其基础解系即为属于 $\lambda_i$ 的线性无关特征向量。

### 1.4 特征值的性质

| 性质 | 表达式 | 说明 |
|------|--------|------|
| 特征值之和 | $\sum \lambda_i = \sum a_{ii} = \operatorname{tr}(A)$ | 等于矩阵的迹 |
| 特征值之积 | $\prod \lambda_i = |A|$ | 等于矩阵的行列式 |
| 多项式的特征值 | 若 $Ax = \lambda x$，则 $f(A)x = f(\lambda)x$ | $f$ 为任意多项式 |
| 逆矩阵的特征值 | 若 $A$ 可逆，则 $A^{-1}$ 特征值 $\lambda^{-1}$ | 特征向量相同 |
| 转置不变性 | $A$ 与 $A^T$ 有相同特征值 | 特征向量不一定相同 |
| 幂的特征值 | $A^k$ 特征值 $\lambda^k$ | 特征向量相同 |

### 1.5 特征向量的性质

- 属于**不同特征值**的特征向量**线性无关**；
- 若 $\lambda$ 是 $k$ 重特征值，则属于 $\lambda$ 的线性无关特征向量的个数 $\le k$；
- 属于同一特征值的特征向量的非零线性组合仍是该特征值的特征向量。

## 二、相似矩阵

### 2.1 定义

设 $A, B$ 为 $n$ 阶方阵，若存在可逆矩阵 $P$，使得

$$P^{-1}AP = B$$

则称 $A$ 与 $B$ **相似**，记为 $A \sim B$。

### 2.2 相似不变性（相似矩阵共享的性质）

| 不变量 | 说明 |
|--------|------|
| 特征多项式 | $|\lambda E - A| = |\lambda E - B|$ |
| 特征值 | $A$ 与 $B$ 特征值完全相同（重数也相同） |
| 行列式 | $|A| = |B|$ |
| 迹 | $\operatorname{tr}(A) = \operatorname{tr}(B)$ |
| 秩 | $r(A) = r(B)$ |

> **注意**：特征向量一般不保持，需通过 $P$ 转换：若 $Bx = \lambda x$，则 $A(Px) = \lambda (Px)$。

### 2.3 相似对角化

若 $A$ 与对角矩阵 $\Lambda = \operatorname{diag}(\lambda_1, \lambda_2, \dots, \lambda_n)$ 相似，即

$$P^{-1}AP = \Lambda$$

则称 $A$ **可相似对角化**，此时 $P$ 的列向量由 $A$ 的 $n$ 个线性无关的特征向量构成。

### 2.4 相似对角化的充要条件

| 条件类型 | 具体内容 |
|----------|----------|
| 充要条件 | $A$ 有 $n$ 个线性无关的特征向量 |
| 充要条件 | 对每个 $k$ 重特征值 $\lambda$，$r(\lambda E - A) = n - k$ |
| 充分条件 | $A$ 有 $n$ 个互不相同的特征值 |
| 充分条件 | $A$ 是实对称矩阵 |

### 2.5 相似对角化步骤

1. 求出 $A$ 的全部特征值 $\lambda_1, \dots, \lambda_n$；
2. 对每个特征值求对应的线性无关特征向量；
3. 以特征向量为列构成 $P$，对应的特征值排成对角阵 $\Lambda$，即 $P^{-1}AP = \Lambda$。

## 三、实对称矩阵与正交变换

### 3.1 实对称矩阵的特殊性质

设 $A$ 为 $n$ 阶**实对称矩阵**（即 $A^T = A$），则：

- $A$ 的特征值**全为实数**；
- 属于**不同特征值**的特征向量**两两正交**；
- $A$ 一定可以**正交相似对角化**，即存在正交矩阵 $Q$（$Q^T = Q^{-1}$），使得

$$Q^{-1}AQ = Q^T A Q = \Lambda$$

### 3.2 正交对角化步骤

1. 求出 $A$ 的全部特征值与特征向量；
2. 对属于同一特征值的特征向量进行 **Schmidt 正交化**（若已正交则只需单位化）；
3. 将所有向量**单位化**，以它们为列构成正交矩阵 $Q$；
4. 得 $Q^T A Q = \Lambda$。

### 3.3 正交变换的意义

正交变换 $x = Qy$ 保持向量的**长度不变**（$\|Qy\| = \|y\|$），因此也称为**保距变换**。这是实对称矩阵对角化在几何上的优雅之处——它用旋转 / 反射（正交变换）将二次曲面旋转到主轴方向。

## 四、二次型

### 4.1 二次型的概念

$n$ 元**二次型**是指：

$$f(x_1, x_2, \dots, x_n) = \sum_{i=1}^n \sum_{j=1}^n a_{ij} x_i x_j = x^T A x$$

其中 $A$ 为 $n$ 阶**实对称矩阵**，称为二次型 $f$ 的矩阵。二次型与实对称矩阵是一一对应的。

### 4.2 合同变换与二次型的化简

若 $P$ 可逆，作变量代换 $x = Py$，则

$$f = x^T A x = (Py)^T A (Py) = y^T (P^T A P) y$$

令 $B = P^T A P$，称 $A$ 与 $B$ **合同**（$A \simeq B$）。

#### 合同的性质

- 合同保持**对称性**；
- 合同保持**秩**不变；
- 合同保持**正负惯性指数**不变（惯性定理）；
- 合同**不保持**特征值和行列式（合同变换本质是配方法 / 线性变量替换）。

### 4.3 标准型

任一实二次型都可通过适当的非退化线性变换 $x = Py$ 化为：

$$f = d_1 y_1^2 + d_2 y_2^2 + \cdots + d_r y_r^2$$

其中 $r = r(A)$。这种形式称为二次型的**标准型**。

化标准型有两种主要方法：

| 方法 | 原理 | 特点 |
|------|------|------|
| **正交变换法** | $Q^T A Q = \Lambda$，取 $x = Qy$ | 得到的标准型系数为特征值，坐标变换是正交的（保距） |
| **配方法** | 逐次配方消去交叉项 | 更灵活，但得不到正交变换 |

### 4.4 规范型

在标准型基础上，进一步令 $z_i = \sqrt{|d_i|}\, y_i$（或直接令系数为 $\pm 1$ 和 $0$），可得：

$$f = z_1^2 + \cdots + z_p^2 - z_{p+1}^2 - \cdots - z_{p+q}^2$$

其中 $p$ 称为**正惯性指数**，$q$ 称为**负惯性指数**，$p + q = r(A)$。

#### 惯性定理

二次型经过任意非退化线性替换化为标准型时，其**正项个数和负项个数是不变的**。换言之，$p$ 和 $q$ 由二次型本身唯一确定。

### 4.5 正定二次型与正定矩阵

若对任意非零向量 $x$，都有 $f = x^T A x > 0$，则称 $f$ 是**正定二次型**，$A$ 是**正定矩阵**。

#### 正定的充要条件

| 编号 | 等价条件 |
|------|----------|
| ① | $A$ 的特征值全部大于 $0$ |
| ② | $A$ 的各阶顺序主子式全部大于 $0$ |
| ③ | $A$ 的正惯性指数 $p = n$（即规范型全为 $+1$） |
| ④ | $A$ 合同于单位矩阵 $E$：存在可逆 $C$ 使 $A = C^T C$ |

## 五、三大关系的彻底梳理

考研中最容易混淆的，莫过于**相似、合同、正交相似**三者。下面一张表说清：

| 关系 | 定义 | 保持的性质 | 丢失的性质 | 关键场景 |
|------|------|------------|------------|----------|
| **相似** $P^{-1}AP = B$ | 同一线性变换在不同基下的矩阵 | 特征值、行列式、迹、秩 | 特征向量需转换 | 一般方阵的相似对角化 |
| **合同** $C^T A C = B$ | 同一二次型在不同变量替换下的矩阵 | 秩、对称性、正负惯性指数 | 特征值、行列式 | 二次型的标准化与规范型 |
| **正交相似** $Q^T A Q = \Lambda$ | 相似 + 合同（$Q^{-1} = Q^T$） | 特征值、秩、行列式、二次型的系数 | — | 实对称矩阵的对角化 |

### 5.1 核心对比：相似对角化 vs 正交相似对角化 vs 合同化简

```
一般方阵
  └─ 相似对角化 ─── P⁻¹AP = Λ（需要 n 个线性无关特征向量）
       │
       └─ 条件：对每个 k 重特征值 λ，r(λE-A) = n-k

实对称矩阵（A^T = A）
  └─ 必然可对角化
       │
       ├─ 相似对角化 ─── P⁻¹AP = Λ（P 由特征向量组成）
       │
       ├─ 正交相似对角化 ─── Q^T A Q = Λ（Q 为正交阵，需正交化+单位化）
       │
       └─ 同时实现"合同化简二次型"── x = Qy ⇒ f = λ₁y₁² + ... + λₙyₙ²
```

### 5.2 关键结论串线

1. **特征值是桥梁**：特征值 $\lambda_i$ 既出现在相似对角化的 $\Lambda$ 中，也是正交变换下二次型标准型的系数；
2. **实对称矩阵 = 三重身份**：
   - 作为方阵：可以相似对角化；
   - 作为对称矩阵：可以正交相似对角化；
   - 作为二次型矩阵：正交变换等于合同化简；
3. **正交变换是"最强"变换**：它同时实现相似对角化、合同化简和保距变换；
4. **惯性指数 ($p, q$) 是合同的"指纹"**：不论采用何种可逆变元代换，$p$ 和 $q$ 永不变；
5. **二次型标准化 $\neq$ 相似对角化**：
   - 相似对角化要求 $P^{-1}AP = \Lambda$，$\Lambda$ 对角线是特征值；
   - 合同标准化要求 $C^T A C = D$，$D$ 对角线是配方法得出的系数（不一定是特征值）。

### 5.3 判定正定的路线图

```
判定 A 是否正定
├─ 路线一（特征值法）: 计算特征值 → 全部 > 0 → 正定
├─ 路线二（顺序主子式法）: 计算各阶主子式 → 全部 > 0 → 正定
├─ 路线三（惯性指数法）: 计算规范型 → p = n → 正定
└─ 路线四（合同法）: A = C^T C, C 可逆 → 正定
```

### 5.4 相似、合同、等价的关系总结

矩阵之间有三种基本等价关系，层层递进：

$$正交相似 \subset 相似 \subset 等价$$

$$正交相似 \subset 合同 \subset 等价（对称矩阵情形）$$

- **等价**：$PAQ = B$（$P, Q$ 可逆），秩相同即等价；
- **相似**：等价 + 保持特征值；
- **合同**：等价 + 保持对称性与惯性指数；
- **正交相似**：相似 + 合同，仅对实对称矩阵有意义。

## 六、考研常见题型与注意点

1. **求特征值与特征向量**：必考题，计算要熟练，尤其注意重根情况下的基础解系；
2. **判定是否可相似对角化**：核心是检查 $r(\lambda E - A) \stackrel{?}{=} n - k$；
3. **实对称矩阵正交对角化**：不要忘记 Schmidt 正交化与单位化这两个环节；
4. **二次型配方法**：配方顺序影响结果形式，但不影响惯性指数（惯性定理的体现）；
5. **正定性判定**：顺序主子式法最快，但必须全部大于 $0$；特征值法最本质；
6. **合同判定**：两个实对称矩阵合同 $\iff$ 正负惯性指数相同（或等价地，规范型相同）。
